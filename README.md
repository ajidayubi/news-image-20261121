This repository features a fully procedural, code-drawn 1024x1024 newspaper front page summarizing Saturday 21 November 2026's major world events. Rendered entirely via native Node.js and TypeScript without external image libraries, downloads, or randomness, it highlights the overnight Russian missile and drone barrage on Ukraine with impacts in Poland, the S&P 500 correction and AI tech rout, Trump and Putin summit remarks, the ICJ genocide ruling on Myanmar, UK-EU post-Brexit agreements, Houthi missile interceptions over Riyadh, COP31 climate deadlock, and global financial and economic headlines. Every run produces byte-identical output.

## Run it with
```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
